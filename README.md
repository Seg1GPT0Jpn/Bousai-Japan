# Bousai Japan（防災ジャパン）

地震・津波のときに「いま何をするか」をすぐ確認できる、無料の防災 Web アプリです。
インストール不要で、ブラウザで開くだけで使えます。一度開くと、電波がなくても使えます（PWA）。

## できること
| 画面 | 内容 |
| --- | --- |
| いま揺れている | 教室・家・駅やお店・外・山やがけ・電車・エレベーターなど、場所ごとの身の守り方 |
| 揺れがおさまった | 次にやること（津波のおそれ、先生の指示、ガラス、火の元、情報、家族への連絡、その後の地震） |
| 津波のおそれ | 「より高いところへ」、歩いて避難、20〜30cmでも危険、後の波、警報中は戻らない |
| 臨時情報が出た | 南海トラフ地震臨時情報（調査中・巨大地震警戒・巨大地震注意・調査終了）の意味と、取る行動 |
| そなえチェック | 家具の固定・非常持出品・避難場所の確認など（チェックはこの端末に保存） |
| 家族メモ | 集合場所・避難場所・連絡先・171で使う番号（この端末の中だけに保存） |
| ツール | ライト（画面を白く光らせる）、呼び笛（音で助けを呼ぶ）、地震からの経過タイマー、171の使い方、公式リンク |

## 大切なこと
- 内容は気象庁・防災庁・文部科学省などの公式資料をもとにしています。各画面の下に出典のリンクがあります。文言を変えるときは出典と食いちがわないようにしてください（内容は `data.js` にまとめています）。
- **このアプリは地震や津波の情報を受け取る機能はありません。** テレビ・ラジオ・自治体・気象庁の情報を確認するよう、画面でも案内しています。
- チェックと家族メモは `localStorage` に保存し、外部には一切送りません。

## 公開のしかた（GitHub Pages）
ビルドは不要です。リポジトリの **Settings → Pages** で、公開するブランチとフォルダ（`/ (root)`）を選ぶと公開されます。

## ファイル
- `index.html` … 画面のわく
- `data.js` … 表示する内容と出典
- `app.js` … 画面の切りかえ・保存・ライト・呼び笛・タイマー
- `style.css` … 見た目（スマホ向け、ダークモード対応）
- `sw.js` … オフライン用（ファイルを足したら `FILES` に追加し、`CACHE` の版を上げる）
- `manifest.webmanifest`・`icons/` … ホーム画面に追加するための設定
