# Bousai Japan（防災ジャパン）

中高生とその家族のための、無料の防災 Web アプリです。
地震・津波のときに「いま何をするか」がすぐわかり、**電波がなくても近くの避難場所を探せます**。
インストール不要（ホーム画面に追加すればアプリのように使えます）。

公開ページ：https://seg1gpt0jpn.github.io/Bousai-Japan/

## できること
| 画面 | 内容 |
| --- | --- |
| ホーム | そなえの達成度、災害時の3つの大きなボタン（いま揺れている／揺れがおさまった／津波のおそれ）、避難場所検索、今日の1問 |
| いま揺れている | 教室・家・駅やお店・登下校・山やがけ・電車・エレベーターごとの身の守り方 |
| 揺れがおさまった／津波 | 次にやること、「より高いところへ」 |
| 避難場所 | 都道府県のデータを端末に保存 → 現在地（GPS）から近い順に、直線距離と方角を表示。災害の種類（地震・津波・洪水など8種類）で絞りこみ。名前・住所でも検索できる。電波がなくても使える |
| 学ぶ | 防災トレーニング（1日1問・解説と出典つき） |
| 家族 | 家族メモ、ロック画面用の「家族の防災カード」画像、QRコードで家族の端末に渡す（サーバーを通らない） |
| そのほか | そなえチェック、南海トラフ地震臨時情報、ライト・呼び笛・経過タイマー・171の使い方 |

## 大切な約束
- 防災の内容は気象庁・防災庁・文部科学省などの公式資料にもとづき、各画面に出典を表示しています（内容は `js/content.js`）。
- 地震や津波の情報を受け取る機能はありません。画面でも、公的機関の指示と情報を最優先にするよう案内しています。
- 現在地・家族メモ・チェックは外部に送りません。現在地は距離の計算にだけ使い、保存しません。
- 避難場所の距離は直線距離で、安全な道順ではありません。

## 避難場所データ
- 出典：国土地理院「指定緊急避難場所・指定避難所データ」（指定緊急避難場所） https://hinanmap.gsi.go.jp/index.html
- 公共データ利用規約（第1.0版）にもとづき、都道府県ごとの JSON に加工して `data/shelters/` に置いています（加工したことをアプリ内に明記）。
- データは市町村が登録したもので、最新でない場合や未掲載の場合があります。アプリ内でも必ず市町村に確認するよう案内しています。
- 更新のしかた（月に1回くらいが目安）：
  ```bash
  python3 scripts/build_shelters.py
  ```
  公式サイトから全国のCSVを取り直して `data/shelters/*.json` と `index.json`（取得日つき）を作り直します。

## ファイル
- `index.html` … 画面のわく
- `css/app.css` … デザイン（ライト／ダーク、片手で押しやすい大きさ）
- `js/content.js` … 表示する内容・出典・クイズ・災害の種類
- `js/app.js` … 画面の切りかえと操作
- `js/shelters.js` … 避難場所の保存・距離と方角の計算（端末内）
- `js/family.js` … 家族メモ・カード画像・QRコード
- `js/icons.js` … アイコン（自作のSVG）
- `vendor/qrcode.js` … QR Code Generator for JavaScript（Kazuhiko Arase, MIT License）
- `sw.js` … オフライン用。ファイルを足したら `FILES` に追加し、`CACHE` の版を上げる
- `scripts/build_shelters.py` … 避難場所データの変換
